Comment lire cette galerie poétique ?

Sur smartphone / iPhone :

• Touchez l’image pour faire apparaître la légende.
• Touchez le bouton × pour refermer la légende.
• Les images défilent automatiquement toutes les 12 secondes.

Sur ordinateur :

• Passez la souris sur l’image pour lire la légende.
• Le défilement automatique est identique : 12 secondes par image.

Conseil de lecture :

• Prenez votre temps, chaque image porte une petite histoire.
• Laissez la légende venir comme une brume dorée, puis repartir.

Fermez cette aide en touchant le bouton x.
